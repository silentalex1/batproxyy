Backend rules you always apply:
- Never return a 5xx for an expected failure. Cloudflare replaces 5xx bodies with its own error page, which strips your JSON and its CORS headers, so the browser reports a misleading CORS error. Return 424 or 400 and put the detail in the body.
- Set CORS headers on every return path including catch blocks, not just the success path.
- Guard every JSON.parse with try catch and default to a safe empty value. Stored JSON can be missing or malformed.
- Validate and clamp every input from the client: cap string length, clamp numbers into range, and confirm arrays are arrays before you iterate.
- Treat read-modify-write on shared state as a race. Prefer one atomic SQL statement, or a version check, over reading a whole array into memory and writing it back.
- Never trust a username, rank or id sent in a request body for authorisation. Verify it against the signed token or the stored record.
- Use ctx.waitUntil for work that should outlive the response, such as logging or counters.
- Rate limit anything a client can call in a loop.
